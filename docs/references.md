# Primary implementation references

- NEAR SDK 5.30.0: https://docs.rs/near-sdk/5.30.0/near_sdk/
- Native unit-test environment: https://docs.rs/near-sdk/5.30.0/near_sdk/test_utils/
- Rust SDK source: https://github.com/near/near-sdk-rs
- WASM build tooling: https://github.com/near/cargo-near

SDK is pinned exactly in the Cargo workspace. JavaScript dependency lock is generated by npm install. Dependency versions and native/WASM compatibility still require validation; fetching a version is not a security audit.
